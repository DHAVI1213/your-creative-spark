# NK Software

SaaS com 8 ferramentas profissionais para criadores de conteúdo.

## Ferramentas

1. **Limpador de Metadados** — Remove localização, aparelho e datas de fotos e vídeos
2. **Clonador de Sites** — Copie um site, edite os textos e baixe para o cliente
3. **Editor em Massa** — Edite um vídeo e aplique em todos de uma vez
4. **Minerador Viral** — Encontre os vídeos que mais estouram num nicho
5. **Minerador de Clientes** — Encontre lojas da sua cidade que precisam de site
6. **Agendador** — Agende Reels, Stories e posts
7. **Legendas e Hashtags** — Legendas prontas por nicho + hashtags
8. **Gerador de Propostas** — Proposta comercial: mensagem WhatsApp + PDF

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
