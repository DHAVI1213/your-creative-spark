Como pegar o token do Instagram
  1. Abra developers.facebook.com/apps e entre no seu app (ou crie um com o caso de uso “Gerenciar mensagens e conteúdo no Instagram”).
  2. Em Funções do app → Funções, adicione a conta como Testador do Instagram e aceite o convite no Instagram (Configurações → Apps e sites → Convites de testador).
  3. Em API do Instagram → Configuração da API com login do Instagram → Gerar tokens de acesso, clique em Adicionar conta e entre com a conta.
  4. Clique em Gerar token, copie e cole abaixo. A nuvem renova ele sozinha.

Para cada conta nova do Instagram, repita a partir do passo 2.

Primeira vez com YouTube: crie as chaves do seu app no Google (uma vez só, vale para todos os canais).

Passo a passo (uns 10 minutos)
  1. Abra console.cloud.google.com e crie um projeto (ex.: “Agendador”).
  2. Em APIs e serviços → Biblioteca, ative a YouTube Data API v3.
  3. Em Tela de consentimento OAuth: tipo Externo, preencha nome e e-mail. Em Público, clique em Publicar app (em modo “Teste” o Google desconecta o canal a cada 7 dias).
  4. Em Credenciais → Criar credenciais → ID do cliente OAuth, tipo Aplicativo da Web. Em URIs de redirecionamento autorizados, cole o endereço abaixo.
  5. Copie o ID do cliente e a Chave secreta para os campos abaixo.

Enquanto o Google não verificar o seu app, ele mostra um aviso na hora de entrar (“app não verificado”: clique em Avançado → continuar) e os vídeos enviados podem ficar privados. Para postar público direto, peça a verificação/auditoria do app no Google.

Primeira vez com TikTok: crie as chaves do seu app no TikTok for Developers (uma vez só).

Passo a passo
  1. Abra developers.tiktok.com, entre e crie um app.
  2. Adicione os produtos Login Kit e Content Posting API (ligue o Direct Post).
  3. Em Login Kit → Redirect URI, cole o endereço abaixo. Peça os escopos user.info.basic e video.publish.
  4. Envie o app para revisão e, enquanto não for aprovado, adicione a sua conta como usuária de teste (Sandbox).
  5. Copie o Client key e o Client secret para os campos abaixo.

Enquanto o TikTok não auditar o app, os vídeos só podem ser postados como “Só eu” (privados). Depois da auditoria, sai público.
